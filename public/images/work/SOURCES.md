# منابع تصاویر preview

این تصاویر screenshot صفحهٔ اصلی سایت‌های عمومیِ نمونه‌کار هستند. هر فایل با اندازهٔ 1440×900 و نسخهٔ 720×450 در همین پوشه قرار دارد.

| فایل | صفحهٔ منبع |
|---|---|
| `mobile-khorsandi-hero.webp` | https://mobilekhorsandi.ir/ |
| `elsa-hamrah-hero.webp` | https://elsahamrah.com/ |
| `php-ielts-house-hero.webp` | https://phpieltshouse.ir/ |
| `isbatab-hero.webp` | https://isbatab.ir/ |
| `danial-rashidi-portfolio-hero.webp` | https://imdanialrashidi.github.io/ |

فرایند دریافت screenshot از مسیر عمومی `https://image.thum.io/` با حالت wait و noanimate انجام شده، سپس تصویر از 1440×1080 به 1440×900 crop و با کیفیت WebP ذخیره شده است. این URLها عمومی‌اند و در صورت تغییر سایت می‌توان تصاویر را با `scripts/refresh-portfolio-previews.sh` تازه‌سازی کرد.

اگر برای استفادهٔ عمومی از تصاویر، مجوز یا سیاست برند جداگانه‌ای داری، screenshotهای خودت را جایگزین کن؛ ساختار و نام فایل‌ها را تغییر نده.
